# Security Policy

## Supported Versions

Security fixes are prioritized for:

- `main` branch
- latest tagged release

Older release lines may not receive fixes.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Use GitHub private advisories:

1. Open the repository Security tab.
2. Click "Report a vulnerability".
3. Provide reproduction details, impact, and affected versions.

Direct link:

- https://github.com/bhavyup/CopyTool-GO/security/advisories/new

## What to Include

- A clear description of the vulnerability
- Steps to reproduce (proof of concept if possible)
- Potential impact and exploitability
- Suggested remediation (optional)

## Response Targets

- Initial triage response: within 3 business days
- Confirmation or need-more-info: within 7 business days
- Fix timeline: depends on severity and complexity

## Disclosure

After remediation and release, maintainers may coordinate responsible disclosure with reporters.
